## 三、各年級數學動態出題器規格

每個年級新增 `src/utils/generators/g<grade>Math.ts`（或分學期檔），並註冊進 `registry.ts` 的 `QUESTION_GENERATORS`。未列出的單元以純文字觀念／性質靜態題為主。

### 五年級下學期（`g5s2Math.ts`）
- `g5s2-math-u1`：第1章 數的十進位結構（大數讀寫、十倍／十分之一、位值換算）
- `g5s2-math-u2`：第2章 分數的計算（帶分數／假分數乘法、分數除以整數）
- `g5s2-math-u3`：第3章 長方體與正方體的體積（體積計算、複合體積、cm³ ↔ m³）
- `g5s2-math-u4`：第4章 小數（三位小數加減、小數乘整數／小數、小數點移位）
- `g5s2-math-u5`：第5章 生活中的大單位（公噸↔公斤、公畝／公頃／平方公里換算）

- `g5s2-math-u7`：第7章 容積（公升↔毫升↔立方公分、有蓋／無蓋容器容積）
- `g5s2-math-u8`：第8章 比率與百分率（比率、百分率互換、打折／加成應用）

## 四、標準出題與驗證 SOP

### 1. 檔案與 ID 命名規範
- **路徑**：`src/data/curriculum/packs/<academicYear>-s<semester>/g<grade>/<subjectId>.json`
- **ID 規則**（確保全庫唯一，避免錯題本與星星進度衝突）：
  - `packId`: `"115-s<sem>-g<grade>-<subject>"`
  - `stage.id`: `"115-s<sem>-g<grade>-<subject>-u<unitNo>"`
  - `question.id`: `"115-s<sem>-g<grade>-<subject>-u<unitNo>-q<index>"`
- **單元對齊**：`stage.curriculum.unitNo` 必須存在於對應 `content/curriculum-sources/<year>-s<sem>/g<grade>/<subject>.json` 的 `units[].unit_no`（**已由驗證器強制**）。

### 2. 學科品質規則
- **Zero Guessing（證據邊界）**：嚴禁捏造未出現在課綱來源中的「課本必考指定生字／Word List」主張；缺乏逐課字表時，改考單元主題理解、閱讀策略、句型文法、科學／社會／生活知識與應用情境。
- **選項與解析**：
  - `options` 必須為 4 個互不重複、非空且語意無二義性的字串（**已由驗證器強制**）。
  - `answerIndex` 必須為 `0..3`，關卡內單一索引不超過半數、題庫包內單一索引不超過 40% 且四個索引皆須用到（**已由驗證器強制**，動態關卡不計入）。
  - `explanation` 需講解「為什麼對／錯在哪裡」；`hint` 給思考線索而不直接洩漏答案（必填）。
- **語音欄位**：
  - 英語題：`speechLang: "en-US"`，`speechText` 填入純英文單字／例句。
  - 其他科目：`speechLang: "zh-TW"`，`speechText` 填入適於中文朗讀的句子（如將 `?` 換成「多少」、`×` 換成「乘以」）。
- **本土語（閩南語／客語）**：現階段缺乏實際臺語／客語音檔，**不出純聽辨發音題**，聚焦詞彙語意、生活對話情境與文化／俗諺知識。

### 3. 批次建置與驗證流程
1. **分波派工**：每波平行派發子代理，請子代理讀完課綱來源 JSON 後以腳本一次生成 JSON 檔，避免單檔多輪寫入造成配額超限。
2. **動態出題器抽測**：新增或修改 `g*Math.ts` 後執行 `npm run test:generators`。腳本會對 `QUESTION_GENERATORS` 的每個出題器生成 24 題，斷言選項恰為 4 個且不重複、`answerIndex` 合法、必填欄位齊全、且內容不含 `NaN`／`Infinity`／`undefined`／`null` 字串。
3. **內容與打包驗證**：
   ```bash
   npm run validate:content
   npm run test:generators
   npm run build
   ```
   確認 `0 錯誤`、`tsc --noEmit` 通過、新增題庫包被 Vite 拆為獨立 async chunk，並檢查結尾的覆蓋率矩陣是否前進。
4. **更新本文件進度表**：每完成一個年級學期批次，同步 §一 的數字（覆蓋率以 `validate:content` 輸出為準，不手算）。

### 4. 模組引用慣例
`src/utils/generators/` 內的相對匯入一律加上 `.ts` 副檔名（`tsconfig` 已開 `allowImportingTsExtensions`）。如此 `scripts/test-generators.mjs` 可直接以 Node 原生型別剝除載入，無須額外建置步驟或第三方 runner。
